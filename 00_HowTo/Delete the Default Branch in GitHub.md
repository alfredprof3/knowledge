# Steps to Delete the Default Branch in GitHub

To delete a default branch in GitHub, follow these steps:

## 1. Change the Default Branch

Before you can delete the default branch, you need to set a different branch as the default. Here’s how:

- Navigate to your repository on GitHub.
- Click on the Settings tab.
- Under the Default branch section, click the dropdown menu next to the current default branch.
- Select a different branch to set as the new default.
- Confirm the change.

## 2. Delete the Old Default Branch

Once the default branch has been changed, you can delete the old default branch:

- Go to the main page of your repository.
- Click on the branch dropdown menu and select View all branches.
- Find the old default branch you want to delete.
- If the branch is associated with an open pull request, you must merge or close that pull request first.
- Click the Delete button next to the branch you wish to remove.

## Important Notes

- Ensure that you have admin access to the repository to perform these actions.
- Deleting a branch that is linked to an open pull request will close that pull request automatically.

By following these steps, you can successfully delete the default branch in your GitHub repository.
