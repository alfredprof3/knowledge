To download an ISO image file for Linux distributions you can do it downloading directly from the website or using `curl` or `wget`

# Debian ISO netinst

```bash
curl -L -O https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.6.0-amd64-netinst.iso
```

```bash
wget https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.6.0-amd64-netinst.iso
```

# ZorinOS ISO

```bash
curl -L -O https://mirror.umd.edu/zorin/18/Zorin-OS-18.1-Core-64-bit.iso
```

