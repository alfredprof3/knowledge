#Whiteboard #Online #Tool #alternative #Excalidraw

Mindmap.so is a whiteboard online tool similar to [[Excalidraw]] that stores files locally in the cache of your computer. If you want to synchronize your files you need to download the file and open in another computer using your favorite browser. It allows ==_Live Collaboration_==. In Live Collaboration you can preview the files and all stuff inside the workspace.
